# 📅 План на 4 тижні

[English](./PLAN.md) · **Українська**

> ℹ️ Джерело істини — англійська версія ([PLAN.md](./PLAN.md)); український переклад може незначно відставати.

**Мета:** почуватися впевнено, будуючи справжній, ідіоматичний Node.js строгим TypeScript —
від основ рантайму до невеликого HTTP API та CLI.

**Передумови:** ти знаєш базовий JavaScript і трохи TypeScript (анотації, інтерфейси,
узагальнення на поверхневому рівні — див. курс-побратим
[TypeScript in a Month](https://github.com/Rossoline/typescript-learn)). Можеш приділяти
**3–4 години на день**, ~5 навчальних днів на тиждень. Потрібен **Node 22+**.

**Темп:** один блок на навчальний день (~3 години): **45–60 хв читання** README + прикладів,
**90–120 хв** на вправи, **15–30 хв** на огляд рішень і коміт. У тижнях закладено запасний
день для повторення чи надолуження.

**Як міряти прогрес:** блок «готовий», коли (1) усі його тести проходять (`npm test`) і
(2) `npm run typecheck` не повідомляє помилок. Комікай після кожного блоку.

## Тиждень 1 — Основи Node
*Від «JS у браузері» до «JS на сервері».*

### Блок 01 — Перші кроки
- Що таке Node.js; рантайм проти браузера; запуск TypeScript через `tsx`.
- Твій перший `node:test`; `process.argv`, `process.env`, `console`.
- **Вправи:** типізоване привітання, парсинг `argv` у користувацькі аргументи, читання env із fallback.

### Блок 02 — Модулі та npm
- ES-модулі проти CommonJS; іменовані та стандартні експорти; специфікатор імпорту `node:`.
- `package.json`, `"type": "module"`, npm-скрипти, залежності.
- **Вправи:** використати вбудовані `node:os`/`node:crypto` через `import`.

### Блок 03 — Шляхи та розташування
- `node:path` (join/resolve/basename/extname); `import.meta.url`; `node:url`.
- Чому `__dirname` треба відтворювати в ESM.
- **Вправи:** будувати кросплатформні шляхи, виводити теку файлу в ESM.

### Блок 04 — Асинхронність у Node
- Інтуїція event loop; promises, `async`/`await`; `util.promisify`.
- Порядок `setTimeout`/`setImmediate`/`queueMicrotask`.
- **Вправи:** промісифікувати callback-API, послідовно проти паралельно, типізований delay.

### Блок 05 — Помилки та процес
- Обробка помилок, error-first callbacks, власні підкласи `Error`.
- `process.exit` та коди виходу; `uncaughtException`/`unhandledRejection` (коротко).
- **Вправи:** обгортка в стилі `Result`, мапінг помилок на коди виходу.

**День повторення тижня 1:** перероби тести, що падають; перечитай блоки 02 і 04.

## Тиждень 2 — Системний I/O
*Читання, запис і потокова обробка даних.*

### Блок 06 — Читання файлів
- `node:fs/promises`: `readFile`, `readdir`, `stat`; кодування; читання JSON.
- **Вправи:** прочитати текстовий файл, перелічити теку, завантажити й розпарсити JSON-конфіг.

### Блок 07 — Запис файлів
- `writeFile`, `appendFile`, `mkdir`, `rm`, `rename`; гарантування тек.
- **Вправи:** записати JSON, додати рядок логу, безпечний «запис у temp, тоді rename».

### Блок 08 — Потоки (Streams)
- `Readable`/`Writable`/`Transform`; `pipe`, `pipeline`; backpressure.
- **Вправи:** трансформувати потік порядково, порахувати байти крізь pipe.

### Блок 09 — Події
- `EventEmitter`: `on`/`once`/`emit`; подія `error`; типізовані мапи подій.
- **Вправи:** типізований емітер, одноразовий waiter, лічильник подій.

### Блок 10 — Buffer та кодування
- `Buffer`, `utf8`/`hex`/`base64`; текст проти бінарних даних; `TextEncoder`.
- **Вправи:** кодувати/декодувати base64, конкатенувати буфери, виміряти довжину в байтах.

**День повторення тижня 2:** поєднати fs + streams у крихітному інструменті «copy & transform».

---

## Тиждень 3 — Будуємо HTTP-сервіс
*Від запиту до відповіді.*

### Блок 11 — Основи HTTP-сервера
- `node:http` `createServer`; `req`/`res`; методи, заголовки, статус-коди.
- **Вправи:** маршрутизація за методом/шляхом, відповіді текстом і JSON.

### Блок 12 — Запити та JSON API
- Парсинг URL та query, читання JSON-тіла запиту, типи контенту.
- **Вправи:** розпарсити тіло, побудувати типізований JSON-обробник, правильні статус-коди.

### Блок 13 — Крихітний роутер та middleware
- Композиція обробників; ланцюжок middleware; 404/500; логування запитів.
- **Вправи:** мінімальний роутер, logging-middleware, межа помилок.

### Блок 14 — Конфіг та середовище
- `process.env`, завантаження `.env`, валідація й типізація конфігу.
- **Вправи:** типізований `loadConfig`, дефолти + обовʼязкові змінні, fail-fast валідація.

### Блок 15 — Сховище даних на файлах
- JSON-персистентність; типізований модуль-репозиторій; застереження щодо конкурентності.
- **Вправи:** `Store`, що завантажує/зберігає JSON, CRUD над файлом.

**День повторення тижня 3:** зʼєднати роутер зі сховищем у міні JSON API.

## Тиждень 4 — Практичний Node та Capstone
*Випуск реальних інструментів.*

### Блок 16 — Дочірні процеси
- `exec`/`execFile`/`spawn`; захоплення stdout/stderr; коди виходу.
- **Вправи:** запустити команду й захопити вивід, стрімити довготривалий процес.

### Блок 17 — CLI-інструменти
- Парсинг `argv` (і `node:util` `parseArgs`); stdin/stdout; прапорці; коди виходу.
- **Вправи:** типізований парсер прапорців, pipe-дружній фільтр, вивід `--help`.

### Блок 18 — Тестування глибше
- `node:test`: `describe`/`it`, setup/teardown, моки та spies, async, coverage.
- **Вправи:** замокати залежність, тестувати async-код, перевірити кинуті помилки.

### Блок 19 — Пакування та скрипти
- `package.json` `bin`, npm-скрипти, semver, `exports`, основи публікації.
- **Вправи:** додати запис `bin`, налаштувати npm-скрипти, валідувати форму `package.json`.

### Блок 20 — Підсумковий проєкт
- Побудувати невеликий **типізований менеджер задач**: файлове сховище, виставлене **через
  HTTP API і CLI**, з помилками в стилі `Result` і повним набором тестів, що проходять.
- **Результат:** усі тести зелені, нуль помилок типів, закомічено у твій форк.

**День повторення тижня 4:** відполіруй capstone, напиши йому README, запуш на GitHub.
